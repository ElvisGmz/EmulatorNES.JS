# Included games

Only games that may be freely redistributed are bundled here. Each one keeps its original, unmodified ROM file
together with its author's notice and license.

| Game | Author | License | Source code |
| --- | --- | --- | --- |
| [LJ65](lj65/README.txt) | Damian Yerrick | [GPL-2.0-or-later](lj65/GPL-2.0.txt) | https://pineight.com/nes/#lj65 |
| [Concentration Room](concentration-room/README.html) | Damian Yerrick | [GPL-3.0-or-later](concentration-room/GPL-3.0.txt) with an exception for exact iNES copies | https://github.com/pinobatch/croom-nes |

LJ65 is not a Tetris product and is not endorsed by Tetris Holding. Concentration Room is not sponsored or endorsed by
Nintendo or any other company named in its notice.

Both ROMs are the same files distributed by [jsnes](https://github.com/bfirsh/jsnes).

## Adding more games

Put the `.nes` file (and its license) in this folder and add an entry to `catalog.json`. Only add games whose license
allows redistribution.
